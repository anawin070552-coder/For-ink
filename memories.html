🌷 MEMORY 01

จุดเริ่มต้นของเรา

เราเจอกันครั้งแรกที่โรงเรียน

ตอนนั้นเธอชวนเค้าทำงานสภาด้วยกัน ซึ่งตอนแรกมันก็ดูเหมือนเป็นเพียง งานธรรมดา ๆ งานหนึ่ง

แต่เค้าไม่รู้เลยว่า การได้ทำงานกับเธอในวันนั้น จะกลายเป็นจุดเริ่มต้น ของเรื่องราวของเราสองคน

🏫 โรงเรียน
🎵 MEMORY 02

วันที่เค้าเริ่มอยากรู้จักเธอ

หลังจากที่ได้ทำงานกับเธอครั้งแรก เค้าก็เริ่มอยากรู้จักเธอมากกว่านี้

เค้าเลยเป็นฝ่ายทักไปหาเธอ แล้วส่งเพลงให้เธอ

จากนั้นเค้าก็ขอจีบเธอ แล้วเราก็ตกลงคุยกัน

💗 จากตรงนั้น เรื่องราวของเราก็เริ่มขึ้นจริง ๆ

🧸 MEMORY 03

วันเที่ยวโรบินสัน

เราได้ไปเที่ยวกันครั้งแรกที่โรบินสัน

เค้าซื้อตุ๊กตาจากตู้ให้เธอ แล้วหลังจากนั้นเราก็ไปดูหนังด้วยกัน

มันอาจเป็นเพียงการไปเที่ยวธรรมดา ๆ สำหรับคนอื่น

แต่สำหรับเค้า มันเป็นหนึ่งในวันที่มีความสุขมาก

วันที่ไปเชียร์บาสที่ศรีราชา
